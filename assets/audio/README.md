# Optional sound pack

Users may place replaceable, license-compatible audio files here:

- `checkpoint.mp3`
- `question.mp3`
- `success.mp3`
- `warning.mp3`
- `failure.mp3`

The application must default to subtle sounds, expose volume/mute settings, never embed a file
without documented redistribution rights, and provide a terminal bell fallback. Audio playback is
specified for Phase 4 and is not claimed by the current MVP.
