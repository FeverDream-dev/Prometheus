# PROMETHEUS Image Generation Prompts

Render these in ChatGPT (DALL-E) or any AI image generator. All prompts share
the FeverDream.dev visual language: **obsidian black backgrounds, gold and
sandstone accents, ancient-meets-technological motifs, glass-morphism panels,
and premium editorial composition**.

## Shared Style Guide (paste before each prompt for consistency)

> **Style**: Dark obsidian background (#0a0a0f). Palette: gold (#DAA520), light
> gold (#F5D76E), dark gold (#B8860B), sandstone (#C5A572), bronze (#8B7355),
> warm white text (#e8e0d4). Aesthetic: ancient wisdom meets cutting-edge AI.
> Subtle radial gold glows. Glass-morphism panels with thin gold borders.
> High-end, premium, editorial quality. No text in the image unless specified.

## Usage Notes

- Generate all images at the specified dimensions or larger, then crop to fit.
- For DALL-E, request "wide" or "square" based on the aspect ratio noted.
- After generation, save to `website/assets/images/` with descriptive filenames.
- The OG card (#1) should be saved as `website/og-card.png` (raster, not SVG).
- The logo mark (#2) should be saved as `website/assets/images/logo-mark.png`.
- All other images can be referenced from documentation or the website.
- Consistency tip: generate images 1-3 first, then reference them as "in the
  same style" when generating the rest.
