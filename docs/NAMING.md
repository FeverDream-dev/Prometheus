# Working name

PROMETHEUS is a strong codename but is already prominent in software, particularly monitoring.
Before public release, perform trademark, package-registry, domain, and app-store searches.

Names closer to the requested "one that challenges/kills gods" concept include Typhon, Porphyrion,
and Godsbane, but each also requires clearance. Keep the product name in one manifest/i18n key so a
rename does not fork protocol identifiers or user data paths.
